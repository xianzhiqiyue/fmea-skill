## Use rules

- prefer the canonical name in outputs
- if the user uses an alias, mention the normalized mapping once
- when retrieving cases, search both the canonical name and the alias terms

## Important note

Do not over-normalize when two names may really mean different scopes.

Example:

- `自动进样器` and `进样筒` are related but not identical scopes

If scope is ambiguous, say so and keep the distinction.
